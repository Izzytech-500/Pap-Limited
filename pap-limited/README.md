# PAP Limited landing page

Landing page for PAP Limited (Promise Afolabi Production Limited, RC 9663236).

Single static file: `index.html` (CSS, JS and images are embedded). Open it in a browser, or host it on GitHub Pages, Netlify or Vercel.

## Before launch
- Add verified YouTube and social media links.
- Confirm the Lagos branch and FUTA store addresses before adding them.

## Publish with GitHub Pages
Repository Settings > Pages > Deploy from a branch > `main` / root.
